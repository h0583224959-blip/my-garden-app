# הגינה שלי

אפליקציית React להצגת פרחים. כל פרח מוצג באמצעות קומפוננטת `Flower`, שמקבלת שם וצבעים דרך `props` ומציגה צבעי ברירת מחדל כשלא נשלחו צבעים.

## הפעלה

```bash
npm install
npm start
```

## בדיקות ובנייה

```bash
npm test -- --watchAll=false
npm run build
```

מערך הפרחים נמצא ב־`src/App.js` ומוצג בעזרת `map`. לחיצה על פרח מציגה הודעה עם שמו.
